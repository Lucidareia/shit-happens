# Missing cat

## What this case is for

A free-roaming cat hasn't come home. This case runs the village search as an organised
mission — maximum efficiency, minimum emotional load: a clear order of actions, a paced
daily rhythm, and a log so the ground you cover stays on record.

## How to use the material

Open [`research-missing-cat-search.md`](research-missing-cat-search.md) — the field guide —
and start at its "Start here — first 60 minutes" section. Then work its numbered sections in
order: search geometry, the sweep, timing, the neighbour canvass, the station-and-camera
setup, trapping, registrations and notifications, and running it all as a paced multi-day
mission with a search log. Sources and confidence labels are in the guide itself.

`index.md` holds the case's status.
